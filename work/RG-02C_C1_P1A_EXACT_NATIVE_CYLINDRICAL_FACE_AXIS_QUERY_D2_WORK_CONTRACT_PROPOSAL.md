## 1. Exact P1-A deliverable and non-goals

Deliver exactly **one new, provider-neutral, read-only geometry capability**: input is an evaluation-local `RuntimeSolidHandle` and one **bound current bounded Face** certified by the same provider and Body generation; output is an exact analytic cylinder's **infinite geometric line and radius**, or typed failure. A partial cylindrical Face (including after Boolean Cut) must be treated as geometry of its supporting analytic cylinder, with no requirement that the Face contains a full circumference. The line has **no authored, persistent or consumption-relevant direction sign**; an arbitrary representative unit vector is permitted. A point on the line is not unique: tests compare **unoriented collinearity and perpendicular axis distance**, not literal Point3 or vector signs.

The provider MUST derive geometry by querying the **actual `TopoDS_Face` in that Body's current `OcctRuntimeSolid::inventory_faces`**, via OCCT `BRepAdaptor_Surface` and its analytic `Cylinder()` (checking `GeomAbs_Cylinder`). Read analytic axis location, `gp_Dir`, positive finite radius using existing mm/world conventions. Never derive from Extrude direction, Revolve input, Fillet parameters, Sketch, creation-feature type, triangulation, bounded edges, sampled-fitting or last-good cached line. **No Part/Axis authoring, no selection/UI, no persistence/schema, no Revolve behavior, no manufactured semantic source identity, no new public Part reference API and no full product feature in P1-A.**

## 2. Explicit Owner-accepted D2 C++ API decision — activation still required

**Choose a dedicated capability, not an extension of the Face-boundary method.** New header:
`src/kernel/include/simplesolid2/kernel/exact_cylindrical_face_axis.hpp`.

- `class ScopedExactCylindricalFace final`: opaque evaluation-local pair of an owning `RuntimeSolidHandle` and `RuntimeFaceToken`. Private constructor, provider-only minted through protected `IExactCylindricalFaceAxisQuery::makeScopedExactCylindricalFace`; default state invalid. `sourceBody()`, `face()`, `valid()` are read-only accessors. Runtime token is **never authored/serialized** and cannot stand alone as authority. Do not alias a `ScopedBoundaryFace` into this capability or let UI fabricate a scope.
- `class IExactCylindricalFaceAxisQuery` with virtual `~...`, `std::optional<ScopedExactCylindricalFace> bindExactCylindricalFaceToBody(RuntimeSolidHandle, RuntimeFaceToken) noexcept`, and `ExactCylindricalFaceAxisResult queryExactCylindricalFaceAxis(RuntimeSolidHandle current_body, const ScopedExactCylindricalFace&) noexcept`. Binding verifies provider-owned Body and membership in **that** runtime inventory. Binding of an existing **noncylinder** is allowed, so query yields the typed `non_cylindrical_surface` result rather than pretending no Face exists.
- `enum class ExactCylindricalFaceAxisStatus`: exactly `ok`, `invalid_input`, `provider_mismatch`, `face_unavailable`, `non_cylindrical_surface`, `invalid_cylinder`, `kernel_failure`. A non-OK result must have **no geometry**; an OK result must have valid geometry.
- `struct ExactCylindricalFaceAxisGeometry`: `kernel::Point3 point_on_axis_world_mm`, `kernel::Point3 unoriented_unit_direction` (representation only, `+d` and `-d` equivalent), `double radius_mm`. `struct ExactCylindricalFaceAxisResult` contains `status`, `std::optional<ExactCylindricalFaceAxisGeometry> geometry`, with `ok()` ensuring atomic valid status+payload. Explicit finite coordinates, unit direction within existing tolerance and strictly positive finite radius; do not silently repair invalid OCCT values.
- `OcctSolidModelingKernel` implements this new **independent interface** alongside `ISolidModelingKernel`, `IFaceBoundaryQuery` and Q0's `IExactBoundedEdgeGeometryQuery`. No OCCT type crosses the public Kernel header. No method or semantics change to existing Face-boundary / Edge geometry APIs.

**Fail-closed/ownership invariant:** a bound Face from Body A cannot be queried against Body B even when numeric `RuntimeFaceToken` values coincide; compare **pointer identity of the owning runtime solid** before inspecting the inventory, as current `queryFaceBoundaryImpl` and `queryExactBoundedEdge3d` do. A wrong provider runtime type, empty Body, unknown token, null/foreign scoped Face, noncylinder, bad numerical axis/radius or caught OCCT exception produces no line. `face_unavailable` is a result state, but if a verified immutable inventory makes its native live reproduction impossible, document **NOT EXECUTED** rather than adding a test-only backdoor. An OCCT face orientation or UV trim reversal must not flip semantic Axis meaning; tests compare lines modulo sign and along-axis translation, not signed vectors. No unexpected mutation, new cache, cross-revision token lookup, fallback or global final-Body topology search.
