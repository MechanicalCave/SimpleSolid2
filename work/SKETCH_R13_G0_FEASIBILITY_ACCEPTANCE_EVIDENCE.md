### G0-02b — solver acceptance and persistent-session risks (donor code inspection; SS2 execution NOT performed)

- Donor `components/SimpleSolid_Sketcher/src/solver/planegcs_sketch_solver.cpp` `PlaneGcsPersistentSession::Impl::solve` explicitly returns `Unsupported` for deferred relations, rebuilds its native session when structural tokens differ, synchronizes **current** geometry and fixed flags when tokens match, solves by `GCS::DogLeg`, calls diagnostic analysis, maps native conflicting/redundant tags to stable donor `ConstraintId`, then reads back a **new evaluated geometry snapshot**. `Converged` alone does not mean accepted: `evaluateSolverAcceptance()` can reject with `ResidualViolation`; uncaught backend exceptions map to `BackendFailure`. These are **donor source facts**, not proof of SS2 integration.
- Donor `solver_acceptance.hpp` checks separate **positive finite distance tolerance in model units** and angular tolerance in radians, checks moved fixed geometry, and compares geometry kind and per-constraint residual. Donor `tests/solver_acceptance_policy_test.cpp` uses a **test-only example policy 1e-6 model distance / 1e-6 radians** and asserts pass/fail for a perturbed Line length, angle, fixed Point and fixed Arc sweep. These values are **NOT** accepted SS2 tolerances or benchmark evidence; SS2 local units/range and numeric resolution require calibration from real fixtures.
- **A1 candidate gate — fixed/projected exactness:** on every attempted solve, accept evaluated Line/Circle/Arc only when the current revision matches, semantic IDs/kinds and cardinalities match, all values and residuals are finite, fixed and PG-01 projected references are unchanged within an explicitly justified tolerance (no silent source mutation), all five first-slice constraints satisfy residual policy, and native diagnostics do not flag a conflict. Reject atomically otherwise, retaining last accepted evaluated snapshot and authored seed. **This policy is a G0 A1 design proposal, not executable acceptance or a source/schema authorization.**
- **Important donor nuance / acceptance STOP:** in `PlaneGcsPersistentSession::Impl::solve()` redundant and partially-redundant native tags produce `SolverDiagnosticKind::RedundantConstraint`, but **only nonempty `conflicting_constraints` triggers `SolveStatus::Conflict`**; a converged solve with a redundant relation can still retain `SolveStatus::Converged`. Thus SS2 A1 must examine diagnostics/explicit duplicate identity and disallow Owner-rejected redundant manual additions atomically even if `SolveStatus::Converged` and numeric residuals appear acceptable. The acceptance interface must differentiate **valid underconstrained** from **redundant** constraints. A test needs two independent paths: ordinary `Converged`/valid residual and injected redundant result; the second must not burn a ConstraintId or advance document revision.
- **A1 negative cases to specify precisely:** degenerate zero-length Lines (avoid undefined angular direction), Circle with zero/negative radius, duplicate Horizontal/Vertical or repeated unordered Line-pair Parallel/Perpendicular, contradictory fixed endpoint geometry, missing Line endpoint role, projected-source equality/stage invalidation, solved nonfinite NaN/Inf and unexplained residual, stale `DocumentRevision` between preview and commit, no-convergence, DoF absent or unknown. Contradictions need deterministic **Command reject diagnostics**; an underconstrained-but-valid Sketch must remain editable. Tests belong to future A1 RED-first allowed paths, not this G0 ledger.
- **Persistent solver session is a cache, never authoritative state:** donor's structural-token/fingerprint logic is an optimization, not a durable SS2 ID contract. The active SS2 `DocumentSession`/Part strict store must own monotonic IDs, command revisions and serialized authored seeds; invalidate/rebuild solver cache upon support frame, projected edge binding, schema migration, Undo/Redo, deletion cascade and session reopen. Confirm cache parity with clean rebuild on exactly the same authorized inputs.
